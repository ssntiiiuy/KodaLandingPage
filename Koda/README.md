# Koda Landing

Landing page estática de Koda, independiente del proyecto de Veterinaria y lista para abrir en VS Code.

## Archivos

- `index.html`: página completa.
- `koda-logo-azul.png` y `koda-logo-claro.png`: variantes del logo usadas por la página.

Mantené estos archivos juntos al copiar o publicar el sitio.

## Verla en tu computadora

Abrí esta carpeta en VS Code. Podés abrir `index.html` en el navegador o usar la extensión Live Server.

## Formulario

El formulario prepara un correo para `santicharruita19@gmail.com` usando la app de correo configurada en el dispositivo. No guarda datos ni envía el mensaje automáticamente desde un servidor.

## Publicarla gratis con GitHub Pages

GitHub Pages permite alojar esta página estática gratis desde un repositorio público. El código del sitio también será público.

1. Crear un repositorio público llamado `koda-landing` en GitHub.
2. Subir `index.html`, los dos logos y este README a la raíz del repositorio.
3. En **Settings → Pages**, elegir **Deploy from a branch**, rama `main` y carpeta `/(root)`.
4. GitHub publicará la página en `https://ssntiiiuy.github.io/koda-landing/`.
5. Abrir esa URL desde un celular. Cuando cargue bien, crear el QR con esa URL y probarlo antes de imprimirlo en el llavero.
